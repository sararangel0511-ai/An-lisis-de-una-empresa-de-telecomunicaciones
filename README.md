# An-lisis-de-una-empresa-de-telecomunicaciones
Análisis de datos para ConnectaTel. Optimicé la oferta comercial y retención mediante el procesamiento de consumo y perfiles con Python (Pandas, Seaborn). El flujo incluyó limpieza de datos, detección de outliers y segmentación de usuarios. Generé insights estratégicos para mejorar la toma de decisiones del negocio. 📊🚀
